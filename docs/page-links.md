# 説明文のページリンク

AppDock 0.131.0以降の対応する説明文では、ページ・設定・コマンドの参照を同じ文章に記述できる。Appletのmanifestで新しいタグを使う場合は`minimumHostVersion`を`0.131.0`以上にする。SDK/Runtimeの追加APIや設定・保存ファイルは不要。

| タグ | 表示とクリック時の動作 |
| --- | --- |
| `[page:text-library]` | 現在の「テキストライブラリー」という名前を表示し、そのページへ移動 |
| `[setting:command-triggers]` | 現在の「コマンドトリガー」という名前を表示し、その設定カテゴリへ移動 |
| `[setting:applet:<Applet ID>]` | 対象Appletの設定へ移動。停止中でも起動・有効化しない |
| `[page:page:<Applet ID>:<ページID>]` | 起動済みAppletの本体内ページへ移動。ページの起動コマンドは実行しない |
| `[command:appdock.text-palette.open]` | 従来どおり、対象を選択したコマンドパレットを開く。明示実行まで実行しない |

本体ページのIDは`src/shared/navigation.ts`、表示名はリボンと同じカタログ、設定カテゴリのID・表示名は`src/shared/settings-navigation.ts`を使う。表示名による検索・別名補完・URLや外部アプリへの移動は行わない。リボンで隠した本体ページも参照できる。

## 構文と適用範囲

共通`DescriptionText`が文章を解析し、`PageLink`と既存`CommandLink`を描画する。既存の`CommandText`入口も同じ共通部品を使う。複数の種類・同一リンクの繰り返しを元の順に表示し、名前は現在のカタログから解決する。名前を再びタグとして解釈しない。

`\[page:text-library]`はタグそのものを表示する。JSONではバックスラッシュを二重に記述する。空ID、不正ID、閉じ忘れ、未知のタグは原文のまま表示する。構文が正しい未知IDは「不明なページ（ID）」の非操作表示とする。停止中、無効、別ウィンドウ表示のAppletページは名前と利用不可の理由を表示し、クリックできる外観にしない。

対象は、[コマンドリンク](command-links-design.md)と同じApplet概要・セクション・項目・設定アクション・一覧編集フィールドのdescriptionと、共通部品を明示的に使う本体の説明文。本体設定の上部説明とパレット設定の2つのSectionにも使用する。利用者の入力値、任意のReactNode、リモートHTML、通知、ログへ自動適用しない。検索など非対話表示は名前へ変換したプレーンテキストにする。参照情報がない文脈ではIDで表示する。

検索用の表示文と元の説明文を分け、参照収集には元の文字列だけを使う。エスケープ解除後の表示文や、解決した名前から新しいリンクを作らない。参照はページごとに必要なIDだけを投影し、共通Mapで参照する。

## 移動と入力

クリック・Enter・Spaceで移動する。リンクは共通アクセント色とフォーカス表示を使い、設定用アイコンまたはページ用アイコンを添える。親セクションの開閉や行の操作へイベントを伝播させない。IME変換中のEnterは移動として扱わない。

既存の入力確定と保存キューを待ち、入力・保存に失敗した場合は値と元の画面を保持する。移動直前に元の接続・session・ページ、発行済み操作ID、元の説明文にある参照と現在の移動先を再確認する。古い接続、削除された参照先、説明文が許可していない移動先は拒否する。

編集ダイアログやオーバーレイが開いている間は移動を拒否し、確定または閉じる操作を案内する。ダイアログ内の未確定入力をページ移動で破棄しない。

移動は`NavigationCoordinator`を使い、[戻る・進む](host-pages.md#戻る進む)へ記録する。成功すると元の設定接続が破棄されることがあるため、専用の本体内部bridgeは移動後に元の設定モデルを返さない。Shell/Applet/リモートHTMLへこのbridgeを公開しない。

## 検証

`tests/page-links.test.cjs`、`tests/command-text.test.cjs`、設定session/client・移動履歴の関連回帰を使用する。`scripts/page-links-ui-test.cjs [固定EXE]`で本体の2画面、Applet説明、混在・エスケープ、入力保持、参照切れ、キーボード、履歴、停止中の非起動、広幅・狭幅を確認する。結果は`VERIFICATION.md`へ記録する。

固定EXEへ `--upgrade-translations` を付けると、旧版の外部翻訳を残した状態から起動し、ファイル全体の置き換えとカスタムコマンド上部のリンクを確認する。
