# 素材ライブラリー

## 範囲と共通基盤

画像と音の管理ページ・選択ダイアログは、実フォルダー、複数所属のグループ、保存順、検索、選択、一括操作、ドラッグ移動、表示状態を共用する。種類ごとの形式検証・プレビュー・試聴はアダプターへ分離する。画像の公開APIと保存形式は維持する。テキスト管理と文字入力パレットは今回の実装対象に含めない。

原素材は共有data/assets/imagesとdata/assets/soundsへ置き、一覧は実ファイルから生成する。分類はimageLibraryとsoundLibraryへ種類別に保存する。フォルダーは保存場所、グループは論理分類であり、一つの素材を複数グループへ所属させられる。登録数の固定上限や別のID索引ファイルは設けない。

共通のファイル基盤は安全なパスの検証、通常監視と既存の補助監視、世代付き読取、排他的な登録、同名同内容の再利用、改名・移動の復旧、ごみ箱削除を担当する。外部移動で所属先が消えた場合、同名候補が一つのときだけ追従する。複数候補や未到着時は参照を保持する。設定用コピーは外部移動追従の対象にしない。音の保管コピーを外部から改変した場合は内容hashの不一致を拒否し、再選択で復旧できる。

管理UIは画像ライブラリーと同じ分類欄・ツールバー・カード・コンテキストメニューを使用する。音のカードには形式・再生時間を表示し、明示操作で試聴する。単一クリックは選択、ダブルクリックまたは試聴操作で再生する。音に画像コピーやアイコンセット取り込みは表示しない。コピー・改名・移動・削除・所属操作は選択全件を対象とする。音の初期カード幅は160px、最小40px。幅・折りたたみ・カード寸法は、種類と管理/選択画面ごとにPC内へ保存する。

## 音と選択

初期対応はWAV。既存の通知音の16MiB制約と共通音声再生の契約を保持し、RIFF/WAVEの構造と再生時間を検査する。試聴も単一audioPlaybackを使い、停止・対象変更・画面終了では、その試聴だけを取り消す。待機と再生中を区別し、音の再生OFFを無視しない。

音選択はフォルダー/グループ/検索で絞り、試聴後に「音を使う」で確定する。取消では親の設定を変更しない。選択したWAVはdata/assets/assigned-soundsへ内容hashで保管し、原素材の改名・移動・内容変更・削除によって設定済みの通知音が変わらないようにする。保管コピーは部分的な設定一覧から自動削除しない。

既存のApplet別通知音と絶対パスの再生は保持する。Webアカウントの音選択を共通ダイアログへ接続し、新規選択は本体の保管コピーを指す参照と表示名を保存する。Node Appletの既存audio.playはこの参照を本体側で解決する。汎用のWAVファイル選択も共通ダイアログを使用し、従来の絶対パス/取消の戻り値を保つ。既存設定の一括移行や、実利用設定への自動変更は行わない。

## 確認

共通化した画像の契約、音の登録・形式拒否・改名/移動/削除の競合と復旧、設定用コピーの独立性、音声キューの試聴取消、選択の確定/取消と呼出元の終了を確認する。音固有のGUIは通知音/Webアカウントと実Node Appletの入口、試聴/停止、選択/取消、改名/移動、狭幅、独立した表示状態と再起動を担当する。共通UIの複数選択・ドラッグ移動・明暗は画像ライブラリーの回帰でも検証する。実スピーカーから聞こえる音とfixtureでの再生開始/終了は区別する。検証結果はVERIFICATION.mdを正本とする。
