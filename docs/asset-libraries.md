# 素材ライブラリー

## 範囲と共通基盤

画像・音・テキストの管理ページと、画像・音の選択ダイアログは、実フォルダー、複数所属のグループ、保存順、検索、選択、一括操作、ドラッグ移動、表示状態を共用する。種類ごとの形式検証・プレビュー・試聴はアダプターへ分離する。画像の公開APIと保存形式は維持する。文字入力パレット・外部アプリへの入力・登録テキストごとの実行コマンドは、管理機能と分けて設計する。

原素材は共有`data/assets/images`・`data/assets/sounds`・`data/assets/texts`へ置き、一覧は実ファイルから生成する。分類は`imageLibrary`・`soundLibrary`・`textLibrary`へ種類別に保存する。フォルダーは保存場所、グループは論理分類であり、一つの素材を複数グループへ所属させられる。登録数の固定上限や別のID索引ファイルは設けない。

共通のファイル基盤は安全なパスの検証、通常監視と既存の補助監視、世代付き読取、排他的な登録、同名同内容の再利用、改名・移動の復旧、ごみ箱削除を担当する。外部移動で所属先が消えた場合、同名候補が一つのときだけ追従する。複数候補や未到着時は参照を保持する。設定用コピーは外部移動追従の対象にしない。音の保管コピーを外部から改変した場合は内容hashの不一致を拒否し、再選択で復旧できる。

管理UIは画像ライブラリーと同じ分類欄・ツールバー・カード・コンテキストメニューを使用する。音のカードには形式・再生時間を表示し、明示操作で試聴する。単一クリックは選択、ダブルクリックまたは試聴操作で再生する。音に画像コピーやアイコンセット取り込みは表示しない。コピー・改名・移動・削除・所属操作は選択全件を対象とする。音の初期カード幅は160px、最小40px。幅・折りたたみ・カード寸法は、種類と管理/選択画面ごとにPC内へ保存する。

## 音と選択

初期対応はWAV。既存の通知音の16MiB制約と共通音声再生の契約を保持し、RIFF/WAVEの構造と再生時間を検査する。試聴も単一audioPlaybackを使い、停止・対象変更・画面終了では、その試聴だけを取り消す。待機と再生中を区別し、音の再生OFFを無視しない。

音選択はフォルダー/グループ/検索で絞り、試聴後に「音を使う」で確定する。取消では親の設定を変更しない。選択したWAVはdata/assets/assigned-soundsへ内容hashで保管し、原素材の改名・移動・内容変更・削除によって設定済みの通知音が変わらないようにする。保管コピーは部分的な設定一覧から自動削除しない。

既存のApplet別通知音と絶対パスの再生は保持する。Webアカウントの音選択を共通ダイアログへ接続し、新規選択は本体の保管コピーを指す参照と表示名を保存する。Node Appletの既存audio.playはこの参照を本体側で解決する。汎用のWAVファイル選択も共通ダイアログを使用し、従来の絶対パス/取消の戻り値を保つ。既存設定の一括移行や、実利用設定への自動変更は行わない。

## テキスト管理

原本はUTF-8の`.txt`。空の本文、日本語、絵文字、複数行を扱い、不正なUTF-8・NULを含むバイナリは拒否する。既存ファイルのBOMとCRLFを保ち、本文が変わっていない保存では原本のbytesを変更しない。人為的な容量上限は設けず、実行環境がBuffer/stringとして扱える範囲で読み込む。

リボンと`appdock.text-library.open`から開く。新規作成・本文編集・複製は共通ダイアログを使い、確定時だけ保存する。本文はEnterとShift+Enterの両方で改行する。IMEの変換確定を優先し、「適用」でファイルへ保存する。複製は元の本文から別ファイルのドラフトを開き、元ファイルを変更しない。同名ファイルへの上書きは拒否する。新規作成と複製は現在のフォルダーへ保存し、選択中の実グループへ追加する。分類保存だけに失敗した場合は作成済みファイルを残し、共通の所属再試行を表示する。

カードには本文冒頭・ファイル名・文字数/行数・グループを表示する。冒頭表示の800 UTF-16コード単位は表示用の抜粋で、保存や検索の上限ではない。選択・ダブルクリック/Enterでの本文表示・コンテキストメニューは共通管理画面へ接続する。本文プレビューは全文をプレーンテキストとして表示する。画像ライブラリー・画像選択のプレビューと横幅をそろえ、右上の「×」・背景クリック・Escapeで閉じる。本文の選択やダイアログ内の余白のクリックでは閉じず、閉じた後は呼び出し元へフォーカスを戻す。「本文を編集」「複製」は1件を対象とし、コピー・改名・移動・削除・所属変更は選択全件を対象とする。Ctrl+Cは本文、Ctrl+Shift+Cはパスをコピーし、本文は一覧の順序で改行区切りに連結する。ファイルとしてのコピーもコンテキストメニューに残す。

検索はファイル名と本文に対する大文字小文字を区別しない部分一致。フォルダー・グループとの積で絞り、グループの保存順を保持する。本文の検索索引はmainのメモリーに共有し、世代が変わったファイルだけ読み直す。検索操作ごとのディスク再読込や本文全体の一覧IPC送信はしない。読み込み中は状態を表示する。

本文の保存では表示時の世代と保存直前の内容を照合し、同じフォルダーの一時ファイルから原子的に置換する。外部エディターやエクスプローラーによる変更・削除・移動が競合した場合は上書きせず、編集ダイアログの入力を保持して通知する。外部移動時のグループ追従は共通の同名単一候補判定を使い、曖昧な候補や欠落参照を勝手に統合しない。

分類は`textLibrary.groups[].files`、PC内表示状態は`textGallery.library`へ保存する。初期カード幅260px・最小40px、分類欄の幅と折りたたみを画像/音と独立して保持する。テキスト選択ダイアログ、設定用保管コピー、文字入力パレットとの接続は提供しない。将来の読取は`TextLibraryService.document`の本文/世代を利用できる。

## 確認

テキスト固有の試験はUTF-8/空本文/BOM/改行、作成・編集・複製・取消、同名拒否、外部編集の競合、本文索引、分類の独立性を担当する。GUIは本文検索・安全な全文表示・選択全件のコピー・現フォルダーへの取り込み・グループ付き作成・フォルダードロップ・狭幅/明暗・表示状態の再起動保持を確認する。実Windowsクリップボードと物理IMEは模擬操作から区別する。

共通化した画像の契約、音の登録・形式拒否・改名/移動/削除の競合と復旧、設定用コピーの独立性、音声キューの試聴取消、選択の確定/取消と呼出元の終了を確認する。音固有のGUIは通知音/Webアカウントと実Node Appletの入口、試聴/停止、選択/取消、改名/移動、狭幅、独立した表示状態と再起動を担当する。共通UIの複数選択・ドラッグ移動・明暗は画像ライブラリーの回帰でも検証する。実スピーカーから聞こえる音とfixtureでの再生開始/終了は区別する。検証結果はVERIFICATION.mdを正本とする。
