# AppDock.at365 0.68.1

## 主な変更

- Default Shellのリボングループの色を、ボタンを囲む枠から左端のバーへ変更しました。持続的に開いた子ボタンの左側まで1本の線でつながります。
- リボンのグループ化、色・名前・アイコンの変更、任意コマンドの配置と右クリック操作、バッジ表示を利用できます。
- 設定画面を本体へ統合し、共通の入力確定・一覧編集・色選択と、PCごとのヒント表示切り替えを整えました。
- Windows標準ショートカットとの入力連携、管理者起動、通知の読み上げ・音の制御、ロック中の通知保留、共通Webアカウントグループを改善しました。
- WallpaperSlideshowのメモリ描画と履歴ページ、WindowsToolsの標準Windows操作を含む現行Appletを同梱します。

## 配布物と導入・更新

Windows x64と.NET 10 Runtimeが必要です。Electron 44.6.0を使用します。

- `AppDock.at365.exe`: 本体のみ。終了後に既存EXEを置き換えるか、アプリ内更新を利用してください。既存のsettings.json・data・extensionsを保持してください。
- `update.json`: 本体のアプリ内更新用情報です。
- `AppDock.at365-all-in-one-0.68.1.zip`: 本体と下表のAppletを含む新規導入用パッケージです。展開して起動し、必要なAppletを有効にしてください。

| 同梱Applet | 版 | 最低本体版 |
| --- | --- | --- |
| Gmail | 0.12.1 | 0.56.0 |
| WallpaperSlideshow | 0.6.4 | 0.66.1 |
| Watch | 0.1.5 | 0.36.8 |
| WebApplet | 0.2.1 | 0.45.0 |
| WebBrowserTools | 0.3.4 | 0.36.8 |
| WindowsTools | 0.2.2 | 0.62.3 |

Appletは各リポジトリの個別Releaseからも更新できます。必要な本体版へ先に更新してください。保存済みの設定・更新元指定は保持します。共有保存先の選択は設計段階で、この版には含みません。

## 検証範囲

標準回帰678件と、固定EXEでのリボンのバー・子との接続・両展開方式・明暗テーマ・色なし・再起動後の保持を確認しました。リリース準備では、新しい配布物の更新・進捗・取消・復旧、全体ZIPの全ファイル照合と隔離起動を確認し、公開後には匿名取得のサイズ/SHA256と更新チェックを検証します。

実Googleログイン・メール受信、実壁紙変更、物理キー・混在DPI、実Windows終了・再起動/UAC操作と実利用先へのインストールは、このリリース検証の対象外です。
