# AppDock 0.69.0

- プロフィールの名前・アバター設定を独立したProfile Appletへ分離しました。リボンは画像のみ・固定名「プロフィール」で表示します。
- 共通画像ライブラリーで原画像の登録・プレビュー・グループ分類ができます。同じ画像を複数のグループへ所属させられます。
- リボンのグループ・コマンド・ページボタンとWebAppletから同じ登録画像を選べます。原画像はリボン以外のApplet本文にも利用できます。
- Applet向けにregistered-image設定、宣言型リボン、Node/.NETの画像登録と生成コピーのAPIを追加しました。

Profile Applet 0.1.0とWebApplet 0.3.0は本体0.69.0以上が必要です。旧プロフィール設定・画像は保持されます。自動移行は行わないため、Profile Appletで名前と画像を設定してください。既存WebAppletのアイコンも保持します。
