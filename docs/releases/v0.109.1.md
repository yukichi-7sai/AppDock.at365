# AppDock.at365 v0.109.1

従来のオールインワンZIPを、指定した6つのAppletを同梱するスターターZIPへ変更しました。本体単体の配布と各Appletの個別更新も引き続き利用できます。

## 主な変更（v0.83.0以降）

- 起動時の自己展開をなくし、フォルダー型のポータブル配布へ移行しました。更新プログラムの進行表示は本体の表示完了まで続きます。
- 表示・一般や本体の設定ページごとに、共有設定とこのPC専用の保存先を切り替えられます。サインイン時の起動・管理者起動・GPU描画の設定はこのPC専用です。
- スタートページの選択、設定一覧の検索・並べ替え・ページ単位の初期化、Applet情報と起動時間の表示を追加・改善しました。
- ショートカット、キージェスチャー、マウスジェスチャー、タッチパッドのコマンドトリガーを整理しました。コマンドスタック、条件、実行方法、実行数を指定できます。
- 固定コマンドパレット、設定内のコマンドリンク、通知センターへの移動、通知の受け取り方、バナーの位置、ダイアログや通知の影を改善しました。
- WebAppletの管理を本体設定へ集約し、画像ライブラリー・画像選択・WebアカウントとMCP設定の共通操作を整備しました。
- 設定・リボン・コマンド一覧の処理と画像キャッシュを改善し、入力中の保存競合、ダイアログ操作、メニュー上のジェスチャー開始を修正しました。

## 導入・更新と動作環境

Windows x64用です。ZIP全体を書き込み可能なフォルダーへ展開し、`AppDock.at365.exe`を起動してください。EXEだけを取り出さず、DLL・resources・localesなどの同梱ファイルも保持してください。Node.jsの別途導入は不要です。.NET Appletの通常ホストには.NET 10 Runtime（Windows x64）が必要です。各Applet固有の要件はそれぞれの開発文書を参照してください。

**旧単一EXE版（前回公開のv0.83.0を含む）からの初回更新は手動で行ってください。** AppDockを完全終了し、本体`update.zip`の内容を既存の配置先ルートへ展開します。旧版の更新プログラムはフォルダー型ZIPに対応していません。既存の設定・data・extensionsは保持し、設定だけを別の配置先へ移動しないでください。フォルダー型へ切り替えた後は本体とAppletの個別・一括更新が利用できます。

新規導入にはスターターZIPを利用できます。同梱Appletの最低対応本体版は各`extension.json`の指定に従い、本体0.109.1は6Appletの要件を満たします。追加Appletは「設定 → Applet管理」から導入できます。

## 検証と制約

型検査・標準回帰、本体と6Appletの発行、配布ZIP/feedのサイズ・SHA256、隔離環境での本体更新・進行表示・中断復旧、スターターの6Applet起動をリリース準備で検証しています。公開後は匿名ダウンロードと実際の更新チェックを照合します。

配布版は未署名です。Windowsの確認画面が表示される場合があります。今回のリリース試験は隔離設定を使用し、利用中の環境への配置、実サービスへのログイン、実際の壁紙変更・Windowsロック、物理複数モニターや混在DPIの網羅確認は含みません。
