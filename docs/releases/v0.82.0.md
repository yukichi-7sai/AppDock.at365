# AppDock.at365 v0.82.0

## 主な変更

- 「設定 → 表示 → 共通」に表示倍率を追加しました。50～200%を選択でき、本体・リボン・Applet・Webページ・通知へすぐ反映します。倍率はPCごとに保存し、再起動後も復元します。.NETが直接表示するウィンドウは対象外です。
- 本体ページと別ウィンドウの切り替え、埋め込みWebアカウント、通知のサイズ・位置も倍率に合わせて調整します。

前回公開版のv0.68.1以降には、次の変更も含まれます。

- プロフィールAppletと共通画像ライブラリー、画像選択・プレビュー・削除確認を追加・整理しました。
- 設定のPC別保存、既定値の省略、ページごとのリセット、入力確定と一覧編集を改善しました。
- テーマとは独立したアクセントカラーとカスタム2色、設定検索・移動・公開コマンドを追加しました。
- 本体のホーム・画像ライブラリー・ログ・通知センター・設定を共通UIへ統合し、Shellは既存7領域を担当する構成に整理しました。
- ショートカットキーとマウスジェスチャーの条件・実行基盤を共通化し、ページ条件、外部アプリ・ブラウザー・デスクトップ条件、同じ入力での先頭/全実行を設定できるようにしました。2段階ジェスチャーと本体の前面化も改善しました。
- MCP接続先の警告表示と設定編集、Applet管理・導入・通知の設定UIを改善しました。

## 配布物と導入

- `AppDock.at365.exe`: 本体の単一EXEです。既存の本体更新にも使用します。
- `update.json`: 単一EXEの版・サイズ・SHA256を示す更新情報です。
- `AppDock.at365-all-in-one-0.82.0.zip`: 同じ本体EXEと全7Applet、収録内容を記録した`bundle.json`を含む新規導入用パッケージです。ZIP全体を展開して起動してください。

既存環境はAppDockの本体更新から更新できます。手動で置き換える場合はAppDockを完全終了し、既存の設定・data・認証情報を保持してください。全体ZIPには利用者の設定やログイン情報を含みません。

## 動作環境と互換性

- Windows x64向けです。Node.jsの別途導入は不要です。
- .NET Appletの通常ホストには.NET 10 Runtime（Windows x64）が必要です。各Applet固有の要件も確認してください。
- 配布版は未署名です。Windowsの警告が表示される場合があります。
- 倍率の既定値は100%です。既存の設定・保存データを自動変換せず、設定の省略項目は現在の既定値を使用します。各Appletの最低本体版は同梱manifestの指定に従います。

## 検証と範囲

表示倍率の関連回帰を含む標準832件と、固定EXEでの本体・Shell・Applet・Web・通知・表示先切り替え・再起動の確認を実施し、利用者による動作確認も完了しています。リリース用の更新・復旧試験、全体ZIPの収録照合・隔離起動、公開後の匿名ダウンロードと更新検出の結果は、リリース検証記録に保存します。

Webアカウントの画面検証はオフラインfixture、通知の表示可否はfixtureを使用しています。実Googleログイン・実メール受信・物理DPI変更・Windowsの実ロック/全画面時通知・実NAS同期を今回の追加検証で確認したものではありません。変更と検証の詳細は[検証記録](../../VERIFICATION.md)を参照してください。
