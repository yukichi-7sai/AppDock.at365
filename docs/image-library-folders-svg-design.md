# 画像ライブラリーのフォルダー・SVG・設定画像の保管

## 目的

画像ライブラリーを実ファイルの一覧として扱い、エクスプローラーによる追加・移動・改名・内容変更を反映する。設定に使用した画像は独立した原本コピーを参照し、素材の整理から表示を独立させる。SVGアイコンはリボンの既定アイコンと同じ配色で描画する。

## 保存と参照

- `data/assets/images/`配下を再帰的に列挙する。フォルダーは実ディレクトリー、グループは複数所属できる設定上の分類。フォルダーで絞り込み、作成・名前変更・移動・空フォルダー削除を行える。画像の移動も実ファイルへ反映する。
- 素材参照の`file`はrootからの相対パスを`/`区切りで保存する。絶対パス・上位参照・リンク経由のroot外アクセスを拒否する。件数で走査を打ち切らない。
- 設定用コピーは`data/assets/assigned-images/<内容SHA256>.<拡張子>`。参照は`{file:"@assigned/<hash>.<拡張子>"}`とする。予約された名前空間は通常のフォルダーとして登録しない。同じ内容は共有し、既存コピーは上書きしない。
- 画像選択の確定時に検証したコピーを用意し、親設定の確定で参照を保存する。親の取消では設定参照を変更しない。設定APIから新たに選択した画像も保存前に保管する。未使用コピーは自動削除しない（他端末・未導入Applet・設定復旧からの参照を保護）。
- 元画像の内容変更はライブラリーへ反映する。設定済みコピーは変更しない。新しい内容を反映するときは再選択する。
- 旧参照の一括コピー・設定移行は行わない。有効な旧参照は読み取り可能なまま扱い、欠落は既定アイコンへ戻す。設定画面で解除・再選択できる。

## グループと監視

起動・通常のファイル監視・既存の任意の補助確認で実階層を照合する。空フォルダーも表示し、コピー途中の画像を読み取り失敗で設定から削除しない。描画は既存の遅延読み込みと画面所有キャッシュを利用する。

グループ参照の相対パスが存在しない場合だけ、拡張子を含む同じファイル名を大文字小文字を区別せず探索する。有効な候補が1件なら追従し、複数・0件なら元の所属を保持する。名前を変えた画像の推測や内容hashでの自動再結合は行わない。分類の更新は既存のrevision・保存競合検査を通す。

## SVG

元bytesを保持する。共通の静的SVG検証で図形・属性を制限し、既存の隔離rendererで描画する。スクリプト・外部参照・外部XML実体・HTML・アニメーションは対象外。表示用画像はPNGへ描画し、SVGをホストDOMへ直接挿入しない。リボンでは形状をマスクとして既定の文字色を使い、明暗テーマ・アクセント・選択状態へ追従する。原本プレビューと通常の画像は元の色を保持する。

## アイコンセット取り込み

初期対応はLucide。素材はアプリに同梱しない。「アイコンセットを取り込む」から明示的に取得する。バージョンを確定した公式配布パッケージをダウンロードし、整合性を確認してSVGとライセンスを`images/Lucide Icon/`へ配置する。パッケージ内のコード・install scriptは実行しない。同名同内容は再利用、異なる内容は既存ファイルを保持して件数と失敗を表示する。取消・通信失敗で完成済み素材は壊さない。

セット名・配布元・展開対象・保存先の定義を共通取り込み処理から分離し、将来の追加を可能にする。自動更新・定期取得は行わない。
