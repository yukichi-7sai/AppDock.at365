# タスクトレイの設定とメニュー

保存型[カスタムコマンド](custom-commands-design.md)も既存のクリック・ダブルクリック・メニューへ選択して割り当てられます。作成だけでは自動でトレイへ追加せず、名前変更後も安定IDで配置を維持します。

「設定 → タスクトレイ」にクリック、ダブルクリック、コンテキストメニュー編集を集約します。一般・ショートカット・Applet詳細のショートカットにはトレイ編集を重複させません。

## 保存

`Settings.trayMenu`が正本です。トップレベルにcommand / separator / group、group.childrenにはcommand / separatorを保存します。項目は独立したidを持ち、同じコマンドを複数位置へ置けます。

```json
{
  "trayMenu": [
    { "id": "open", "type": "command", "command": "appdock.open" },
    {
      "id": "daily",
      "type": "group",
      "title": "よく使う操作",
      "children": [
        { "id": "pause", "type": "command", "command": "appdock.gestures.togglePause" }
      ]
    }
  ]
}
```

未取得コマンドもトップレベルへ保持します。明示した空配列はそのまま残し、解除した項目を再生成しません。

`trayCommands`は新形式が存在する場合、配置されたコマンドIDの重複を除いた派生値です。単独で編集しても新形式を上書きしません。新形式での追加は検証エラーにし、ホスト側から必ず末尾に「設定…」「終了」を付加します。

## 編集と実メニュー

`TraySettings.tsx`はuseSettingsEditorの保存済みvalue/JSON/revisionと即時保存キューを共用します。選択用CommandPaletteは実行せず、クリック先・ダブルクリック先・追加するコマンドを返します。配置操作は変更時に保存し、保存成功後に実メニューへ反映します。グループへのドロップで末尾へ入り、項目へのドロップでその直前へ移動します。グループを別グループの子にはできません。上下ボタン・ハンドルの上下キーは同じ階層内で移動し、配置先の選択でトップレベルと各グループを移動します。削除ボタンは共通SettingsDialogで対象を確認し、取消では変更しません。確認中にメニューが変わった場合は削除を止めます。グループ解除も確認を経て子を同じ位置へ戻し、コマンドを削除しません。

shared/tray-menu.tsがプレビューと実メニューの項目を解決します。空グループ、先頭/末尾/連続の区切り線は表示しません。未知/利用不可コマンドは設定に保持して無効表示し、コマンド再登録で表示名と利用可否を更新します。Appletのtrayラベル提案は従来通り参照し、IDを実行対象とします。設定保存・外部設定編集・Applet状態/コマンド変更で実メニューを再構成します。グループ名や項目名の`&`はElectronのニーモニックとして解釈させず文字として表示します。

`appdock.gestures.togglePause`はhostCommandsと共通executeCommandへ登録します。検索・ショートカット・トレイ・クリックから実行でき、ウィンドウを開かず一時停止/再開を切り替えます。トレイ内の同コマンドはcheckboxになり、いずれの経路で実行しても全配置のチェック状態を再構成します。一時停止状態は保存せず、本体再起動で解除します。ジェスチャーを使って一時停止した場合、再開はトレイ・検索・キーなどから行います。

## 外部編集

MCPからメニューとシングル/ダブルクリック割当をまとめて取得・変更できます。形式と許可は[共通操作API](automation.md#タスクトレイ編集)が正本です。外部編集は設定保存だけを行い、割当コマンドをその場で実行しません。設定保存時は既存applySettingsが保留クリックを取り消し、実メニューを再構成します。シングルは1コマンド必須、ダブルはnullで解除できます。

共通SettingsSectionでクリック動作と「コンテキストメニュー」を分離する。前者のカードはSectionのtitle・description・折りたたみを付けず、SettingsFieldで単/ダブルクリックの選択を常時表示する。コマンド選択ボタンはそれぞれの入力領域の横幅いっぱいに表示する。後者は追加ツールバー、編集一覧、プレビューをまとめ、追加と上下移動には[共通アクセントボタン](appearance.md)を使う。上下移動・削除/グループ解除は各行の中に配置し、選択項目の編集欄へ重複させない。保存形式・実行経路・並べ替えとグループ解除の意味は変更しない。

編集一覧は行と一覧全体の外枠を置かず、名前とコマンドID/グループ件数を1行で表示する。長い文字は省略表示し、名前とIDはtooltipで全文を確認できる。行はコンパクトにし、ドラッグ・選択・上下・削除の操作領域は保持する。子項目はインデントと縦の補助線でグループを示す。クリック/ダブルクリックのFieldはコマンド名と利用不可の状態だけを表示し、IDは表示しない。保存されたIDと選択・解除・実行は変更しない。固定の「設定…」「終了」は表示イメージと実メニューにだけ残し、編集一覧には表示しない。
