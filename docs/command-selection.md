# 共通コマンド選択ダイアログ

設定のコマンド選択は本体rendererの`CommandSelectionDialog`を共用する。リボンのボタンと右クリック、トレイのクリックとメニュー追加、カスタムコマンドと各トリガーのコマンドスタックから開く。入口は`CommandSelectButton`、モーダル・取消・フォーカス管理は`SettingsModal`を使う。

## 検索と表示

- 上部に検索、絞り込み解除、表示件数/全件数を置く。名前・説明・提供元・IDをNFKC/大文字小文字正規化して検索し、空白区切りの語はすべて一致する候補を表示する。
- 提供元一覧は「すべて」「お気に入り」、本体・カスタムコマンド・各Applet。Appletの所有元は安定IDで区別し、同じ表示名でも混ぜない。初期幅は170px。境界のドラッグ、左右キー（10px単位）、Home/Endで幅を調整し、ダブルクリックで初期幅へ戻す。幅はダイアログ内だけに保持し、再度開くと初期幅に戻る。最小120pxとし、コマンド一覧に240pxを残す範囲で調整する。狭幅では境界を隠し、共通`FilterSelect`へ切り替える。
- お気に入りは既存のピンを読み取る。選択ダイアログ内では追加・削除・並べ替えを行わない。設定ページの`auxiliary.commandPins`には、そのページの候補に含まれるIDだけを投影する。設定値・保存対象へ混ぜない。
- 一覧は名前・提供元・現在の設定・利用できない理由を表示する。詳細欄は説明とIDを表示する。説明内のコマンド参照は現在名のテキストへ解決し、実行リンクを置かない。
- 呼び出し元の候補制限、非表示コマンド、トレイ固定項目の除外、スタック自身の除外を保持する。停止中でも登録可能な候補は選べる。候補へ件数上限を追加しない。
- カタログ更新を反映し、候補が削除されたら選択を解除する。代わりの候補を自動選択せず、明示的に選ぶまで確定できない。検索条件や親の入力を勝手に初期化しない。既存設定の参照表示用に保持する`UiCommand.missing`は新しい選択候補に含めない。

## 操作と保存

検索欄へ初期フォーカスを置く。変更時は現在のコマンドを選択・スクロール表示し、検索欄は空にする。1回のクリックは候補の選択だけで、選択ボタン・Enter・ダブルクリックで確定する。上下キーで移動し、一覧にフォーカスがある場合はHome/Endも使える。IME変換中・キーリピート・修飾キー付き入力では確定しない。

キャンセル・Escape・閉じるボタンでは親の値を変更しない。閉じた後は元の操作へフォーカスを戻す。親の編集ダイアログは表示中もマウントを保ち、一時入力・検索・スクロール位置を保持する。背景クリックでは確定・取消しない。

確定時に最新の呼び出し元候補を再照合してコマンドを返す。選択自体は実行・Applet起動・設定保存を行わない。トレイ等の即時保存、リボンボタンやスタックの親ダイアログ確定、失敗と競合検査は呼び出し元が所有する。

ダイアログの基本幅は920px・高さは900pxとし、共通モーダルの上限で画面内へ収める。検索結果で高さを変更せず、検索と確定操作を常に表示する。詳細欄は80px（画面高520px以下では64px）に抑えて、残りの高さを一覧へ割り当てる。一覧と長い詳細はそれぞれ内部をスクロールさせる。配色・スクロールバー・入力寸法は[共通UI指針](settings-ui-guidelines.md)に従う。

## 実行パレットとの関係

実行用コマンドパレットと説明内の`CommandLink`は従来の実行経路を使う。`CommandPaletteRequest`は`mode: execute`だけを受け付け、選択用の候補・ピン・ショートカット上書きと`selected`結果は持たない。設定ページからは有効な`initialCommandId`を指定したコマンドリンクだけを受け付ける。旧選択要求は実行へ読み替えず拒否する。

## 検証

検索・所有元・非表示/停止中・件数は`tests/command-selection.test.cjs`、実際の確定・取消・親入力・フォーカス・IME・狭幅・更新・再起動は`scripts/command-selection-ui-test.cjs [固定EXE]`で確認する。実行パレットの拒否・実行・ピンと復旧は既存のパレット回帰へ残す。
